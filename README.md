# TP2-Js

Trabajo práctico de JavaScript de Rolling Code School. Son 17 ejercicios sobre bucles, validación de datos, `Math` y `String`.

## Tecnologías

- HTML5 / CSS3
- JavaScript (Vanilla)
- Bootstrap 5 (CDN)

## Estructura

```
TP2-Js/
├── index.html
├── css/style.css
└── js/tp2/ejercicio1.js ... ejercicio17.js
```

`index.html` carga un solo script a la vez (`./js/tp2/ejercicioN.js`). Para probar otro ejercicio, cambiá esa ruta.

## Cómo ejecutarlo

1. Descargá o cloná este repositorio en tu computadora.
2. Abrí `index.html` en el navegador (recomendado: extensión Live Server).
3. Los ejercicios usan `prompt()`, `alert()` y `confirm()`.

## Descarga

Podés descargar el proyecto desde este repositorio usando el botón **Code > Download ZIP**, o clonarlo con:

```
Git clone:
https://github.com/amaliafernandez/TP2-js
```

## Ejercicios

1. Validar edad y mensaje si puede conducir.
2. Calificación según nota (0-10).
3. Concatenar cadenas hasta "cancelar".
4. Sumar números hasta "cancelar".
5. Calcular letra de DNI.
6. Pirámide numérica (1 al 30).
7. Pirámide inversa (1 al N).
8. Pirámide ascendente (1 al N).
9. Números 1-500 con múltiplos de 4 y 9.
10. Tabla de filas/columnas en orden descendente.
11. Mayor edad entre 3 personas (Math).
12. Número aleatorio entre 1 y 99 (Math).
13. Texto a mayúsculas (String).
14. Insertar guiones entre caracteres (String).
15. Contar vocales (String).
16. Invertir cadena (String).
17. Posición de la primera vocal (String).
